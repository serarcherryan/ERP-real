# Auto Harness Protocol

## 1. 目的

本协议用于让 AI 在写代码时自动执行 Harness Engineering 流程。它把项目治理、模块设计、接口契约、质量门禁、安全合规和发布检查变成开发前后的固定步骤。

## 2. AI 自动判断流程

收到任务后，AI 必须先判断任务类型：

| 任务类型 | 必须动作 |
| --- | --- |
| 新业务模块 | 创建模块设计文档，必要时创建 API/事件契约 |
| 新接口 | 创建或更新 API 契约 |
| 新异步流程 | 创建或更新事件契约 |
| 权限/审计/租户变更 | 更新模块设计，补权限与审计测试 |
| 数据迁移 | 更新发布变更文档或模块发布计划 |
| 高并发路径 | 补容量、限流、缓存、幂等和压测说明 |
| 架构/基础设施选择 | 创建 ADR |
| 小修复 | 检查是否影响契约、权限、审计和测试 |

## 3. AI 开发前 Prompt 模板

当你要求 AI 开发功能时，推荐这样描述：

```text
请按照 AGENTS.md 和 docs/10-ai-collaboration/auto-harness-protocol.md 执行。

目标:
业务背景:
影响端:
影响模块:
用户角色:
验收标准:
高并发要求:
权限/审计要求:
数据迁移:
不允许修改:
```

如果某些字段缺失，AI 应根据现有文档做保守假设；只有当缺失信息会导致权限、数据、财务、医疗或生产风险时才需要停下来询问。

## 4. AI 执行顺序

```text
理解任务
-> 搜索现有文档和代码
-> 判断影响域和风险等级
-> 创建/更新 Harness 文档
-> 设计 API/事件/数据/权限边界
-> 实现代码
-> 添加或更新测试
-> 运行可用检查
-> 总结验证结果和风险
```

## 5. 文档自动生成规则

### 新模块

复制：

```text
docs/04-modules/module-template.md
```

生成到：

```text
docs/04-modules/<module-name>.md
```

必须填写：

- 模块档案
- 业务目标
- 核心流程
- 领域模型
- API 与事件
- 权限与数据范围
- 并发与一致性
- 测试计划
- 发布计划

### 新 API

复制：

```text
docs/03-apis/api-contract-template.md
```

生成到：

```text
docs/03-apis/<module>-<action>.md
```

必须填写：

- Endpoint
- Request/Response
- Error Codes
- 权限要求
- 审计要求
- 性能与限流
- 测试清单

### 新事件

复制：

```text
docs/03-apis/event-contract-template.md
```

生成到：

```text
docs/03-apis/<event-name>-event.md
```

必须填写：

- 事件语义
- Payload
- 幂等键
- 顺序要求
- 消费失败策略
- 监控指标

### 新架构决策

复制：

```text
docs/09-decisions/ADR-template.md
```

生成到：

```text
docs/09-decisions/ADR-000X-<decision-title>.md
```

必须填写：

- Context
- Decision
- Options Considered
- Consequences
- Validation

## 6. 自动质量门禁

AI 在结束任务前必须自查：

| 检查项 | 问题 |
| --- | --- |
| 模块边界 | 是否修改了非 owning domain 的数据？ |
| 租户隔离 | 是否所有业务查询都带租户/机构边界？ |
| 权限 | 是否校验了角色、数据范围和字段可见性？ |
| 审计 | 高敏感读取或修改是否记录审计？ |
| 幂等 | 重复提交是否安全？ |
| 并发 | 是否存在竞态、重复扣费、重复发药、重复任务？ |
| 性能 | 是否分页、限流、缓存或异步化？ |
| 日志 | 是否避免输出敏感数据？ |
| 测试 | 是否覆盖正常、异常、越权、并发或状态机？ |
| 发布 | 是否有迁移、灰度、回滚或 Feature flag 说明？ |

## 7. 可跳过文档的情况

以下情况可以不新增 Harness 文档，但 AI 必须在最终说明中写明原因：

- 纯文案修改
- 纯样式修复
- 测试代码内部整理
- 不改变行为的局部重构
- 修复拼写、格式化或注释

## 8. 最终输出格式

AI 完成后应输出：

```text
已完成:
- 

Harness 文档:
- 

验证:
- 

风险/备注:
- 
```
